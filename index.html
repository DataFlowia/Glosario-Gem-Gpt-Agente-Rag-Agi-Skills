¿Qué hay detrás de ChatGPT y cómo genera sus respuestas?

GPT significa Generative Pre-trained Transformer. El término puede referirse a una familia de modelos que procesan y generan lenguaje o, en ChatGPT, a un asistente personalizado configurado para una finalidad concreta.

Analogía: es como un redactor muy veloz que ha leído muchísimo: escribe con soltura, pero necesita que le expliques con claridad qué quieres.

Ejemplo práctico: Analista Comercial

Un asistente puede examinar una tabla de ventas, calcular indicadores, distinguir datos de interpretaciones y proponer acciones comerciales justificadas.

Prompt de ejemplo

Actúa como analista comercial. Examina los datos de ventas que te proporcionaré. Calcula los indicadores posibles, explica los resultados en lenguaje sencillo, distingue los datos observados de tus interpretaciones y propone tres acciones comerciales justificadas. Si falta información, solicítala.

Usos cotidianos

  • Redacción y síntesis de documentos.
  • Análisis de información y apoyo a decisiones.
  • Planificación, programación y generación de ideas.

¿Cuándo elegirlo?

Cuando necesitas un asistente recurrente con instrucciones, criterios y herramientas definidas.

Gem

Un asistente personalizado dentro de Google Gemini

¿Cómo hago que Gemini trabaje siempre a mi manera?
PersonalizaciónGoogle Gemini

¿Cómo hago que Gemini trabaje siempre a mi manera?

Un Gem es un asistente configurado para una función determinada mediante instrucciones específicas y, según las funciones disponibles, información de referencia.

Analogía: es como trabajar con un especialista al que le explicas qué debe hacer y cómo quieres que trabaje.

Ejemplo práctico

Crea un Gem llamado “Profesor IA para principiantes”. Define el público, el tono, la estructura de las clases y la regla de no inventar datos. Así tendrás una base consistente para preparar lecciones.

Usos cotidianos

  • Preparar clases, ejercicios y evaluaciones.
  • Crear publicaciones y propuestas para un emprendimiento.
  • Ordenar pendientes y estructurar planes semanales.

¿Cuándo elegirlo?

Cuando repites tareas y quieres mantener una metodología dentro de Gemini.

RAG

Respuestas contextualizadas con fuentes externas

¿De dónde saca la información para responder?
DocumentosRecuperación

¿De dónde saca la información para responder?

RAG significa Retrieval-Augmented Generation o generación aumentada por recuperación. El sistema busca información relevante en fuentes externas y la entrega al modelo como contexto para elaborar una respuesta.

Analogía: es como un examen a libro abierto: antes de responder, el sistema consulta los apuntes correctos.

Cómo funciona

  1. Pregunta: “¿Qué requisitos establece el reglamento?”
  2. Recuperación: busca fragmentos en documentos autorizados.
  3. Contexto: entrega los fragmentos pertinentes al modelo.
  4. Respuesta: genera una explicación que puede incluir citas o referencias.
  5. Verificación: se comprueba que las fuentes respalden la respuesta y estén vigentes.

Usos cotidianos

  • Consultar actas, contratos y reglamentos.
  • Buscar información en manuales técnicos.
  • Responder preguntas sobre catálogos o procedimientos internos.
Ojo: RAG no garantiza la verdad: los documentos desactualizados, las búsquedas deficientes o las fuentes incompletas pueden producir respuestas erróneas.

¿Es lo mismo que cargar un PDF?

No necesariamente. Una arquitectura RAG puede incluir fragmentación, indexación, búsqueda semántica, filtros de acceso y recuperación de fragmentos relevantes.

Skills

Procedimientos especializados y reutilizables

¿Cómo repito un procedimiento sin explicarlo cada vez?
ModularidadProcedimientos

¿Cómo repito un procedimiento sin explicarlo cada vez?

En sistemas de agentes, una skill es una capacidad o procedimiento reutilizable. Puede reunir instrucciones, recursos, plantillas y, en ciertos formatos, scripts para realizar una clase de tareas de forma consistente.

Analogía: son como recetas de cocina: cada una explica paso a paso cómo preparar un plato y puedes usarla cuando quieras.

Ejemplo: informe mensual con cuatro skills

  1. Leer y validar datos de Excel.
  2. Calcular indicadores comerciales.
  3. Crear gráficos y tendencias.
  4. Redactar un informe ejecutivo.

Otros usos

  • Resumir documentos.
  • Limpiar planillas y detectar anomalías.
  • Organizar argumentos académicos.
  • Crear presentaciones o revisar código.
Nota: el término también puede significar habilidades de un modelo o funciones de una aplicación. Aquí se usa principalmente como módulo de trabajo reutilizable para agentes.

Agente

Coordina pasos y utiliza herramientas para lograr un objetivo

¿Quién se encarga de ejecutar los pasos de un proceso?
Flujos de trabajoHerramientas

¿Quién se encarga de ejecutar los pasos de un proceso?

Un agente de IA es un sistema que combina un modelo, instrucciones y, cuando corresponde, herramientas para avanzar hacia un objetivo en uno o varios pasos.

Analogía: es como un asistente de oficina con una lista de tareas y llaves limitadas: hace los pasos, pero tú decides hasta dónde puede llegar.

Ejemplo: seguimiento comercial

  1. Recibir una consulta nueva.
  2. Clasificar la necesidad y detectar datos faltantes.
  3. Preparar una respuesta y una propuesta preliminar.
  4. Registrar datos en un sistema autorizado.
  5. Solicitar aprobación humana antes de enviar ofertas o asumir compromisos.

Usos cotidianos

  • Extraer datos de documentos y preparar informes.
  • Clasificar consultas y preparar seguimientos.
  • Coordinar investigación, programación y pruebas.
Control responsable: limita permisos, registra acciones y solicita aprobación humana para decisiones importantes. Más autonomía no siempre significa mejores resultados.

AGI

Inteligencia Artificial General: un concepto de investigación

¿Hasta dónde podría llegar la inteligencia artificial?
FuturoInvestigación

¿Hasta dónde podría llegar la inteligencia artificial?

AGI significa Artificial General Intelligence. Describe una inteligencia artificial hipotética capaz de aprender, razonar y adaptarse a una amplia variedad de tareas intelectuales, transfiriendo conocimientos entre dominios.

Analogía: piensa en la diferencia entre una calculadora excelente en una sola tarea y una persona capaz de aprender oficios muy distintos.

Ejemplo para comprenderla

Imagina un sistema que aprende economía, estudia un problema de ingeniería, comprende literatura y aplica conocimientos anteriores a una situación nueva con gran flexibilidad.

¿Qué aporta hoy este concepto?

  • Ayuda a analizar posibles cambios en la educación y el trabajo.
  • Invita a evaluar qué tareas requieren juicio humano.
  • Abre preguntas sobre seguridad, empleo y gobernanza tecnológica.
Importante: la AGI no es una aplicación que debamos instalar. Su definición sigue en debate y no debe atribuirse automáticamente a los asistentes actuales.
